# 视觉与交互基线

## 品牌

- 名称：**OpenShop 开集**。
- 口号：**逛得开，买得值。**
- 品牌性格：热闹但克制，有集市烟火气，也有清晰的交易秩序。
- 图形语言：开集的“棚顶/门”抽象为三段式遮棚标记；圆角与折角并置。

## 色板（设计 token）

| Token | 值 | 用法 |
| --- | --- | --- |
| `--paper` | `#f6f1e8` | 页面底色 |
| `--paper-raised` | `#fffaf2` | 卡片/浮层 |
| `--ink` | `#221b16` | 主文字 |
| `--muted` | `#75695c` | 次级文字 |
| `--line` | `#e5d9c8` | 分隔线 |
| `--accent` | `#d7462c` | 主行动/价格 |
| `--accent-deep` | `#a62e1c` | hover/深色行动 |
| `--jade` | `#1e6f5c` | 自营与可信标识 |
| `--honey` | `#e7b457` | 活动/高亮 |
| `--night` | `#1d2925` | 页脚/反色块 |

字体：标题用系统中可用的宋体/衬线族，正文用系统中黑体/无衬线族。禁止外链字体。

## 版式

- 桌面最大内容宽 1320px，主留白 28-48px；移动 16px。
- 卡片圆角 16-22px；交互目标最小 44×44px。
- 首页首屏必须有一个明确主活动（非轮播自动跳动）、搜索入口和至少一条可信承诺。
- 价格用 `.price`，人民币符号更小；原价删除线；不要用闪烁/抖动制造焦虑。

## 内容

- 所有品牌、店铺、商品、人物、评价均为虚构；不得出现真实平台 Logo、UI 截图、版权图片。
- 商品图采用项目自绘矢量场景：暖色背景、抽象材质、明确的商品轮廓、细腻阴影与纸感纹理。
- 文案短、具体、有信息；禁止“惊呆了”“最后 X 件”“手慢无”等虚假或施压措辞。

## 动效与无障碍

- 仅使用 `transform`/`opacity`；`prefers-reduced-motion: reduce` 时关闭。
- 所有图标按钮有 `aria-label`；图片有有意义 alt；对话框使用 `role=dialog` 与焦点循环。
- 键盘可完成搜索、加购、加减数量、打开结算；Esc 关闭浮层；错误信息带 `role=alert`。
- 文本对比度 ≥ 4.5:1（大号 ≥3:1）。焦点环不可移除。

## 页面模块边界

- Shell、路由、会话、API、按钮/图标/商品卡/Toast/登录浮层：Lead 所有。
- 首页、搜索、商品详情：discovery 页席所有，并在页内引入自己的 CSS。
- 购物车、结算、账户/订单：flow 页席所有。
- 商家台：merchant 席所有。
- 设计增强只能通过新增 `web/css/theme.css` 或维护 tokens/assets 完成，不覆盖页面模块的写集。
